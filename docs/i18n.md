# Internationalization (i18n)

## Overview

Uses **next-intl** with locale-based URL routing (`/th/...`, `/en/...`).

## Configuration

| File | Role |
| --- | --- |
| `src/i18n/config.ts` | Locale list and default locale |
| `src/i18n/routing.ts` | Routing definition + navigation exports (Link, useRouter, etc.) |
| `src/i18n/request.ts` | Server-side message loading |

### Supported Locales

```typescript
// src/i18n/config.ts
export const locales = ['th', 'en'] as const
export const defaultLocale = 'th'
```

## Translation Files

Located in `src/messages/{locale}/common.json`:

```
src/messages/
├── th/common.json    # Thai translations (default)
└── en/common.json    # English translations
```

### Structure

```json
{
  "app": {
    "name": "Project Name"
  },
  "nav": {
    "home": "หน้าแรก",
    "login": "เข้าสู่ระบบ"
  },
  "auth": {
    "loginTitle": "เข้าสู่ระบบ",
    "username": "ชื่อผู้ใช้"
  },
  "common": {
    "save": "บันทึก",
    "cancel": "ยกเลิก"
  }
}
```

## Usage in Components

### Server Components

```typescript
import { useTranslations } from 'next-intl'

export default function HomePage() {
  const t = useTranslations('nav')
  return <h1>{t('home')}</h1>
}
```

### Client Components

```typescript
'use client'
import { useTranslations } from 'next-intl'

export default function LoginForm() {
  const t = useTranslations('auth')
  return <Button>{t('loginButton')}</Button>
}
```

## Navigation

Always use next-intl's navigation exports (locale-aware):

```typescript
import { Link, useRouter, usePathname } from '@/i18n/routing'

// Link
<Link href='/dashboard'>Dashboard</Link>

// Programmatic navigation
const router = useRouter()
router.push('/dashboard')

// Current pathname (without locale prefix)
const pathname = usePathname()  // '/dashboard', not '/th/dashboard'
```

## Language Switcher

`src/components/common/language-switcher.tsx`:

```typescript
const switchLocale = () => {
  const nextLocale = locale === 'th' ? 'en' : 'th'
  router.replace(pathname, { locale: nextLocale })
}
```

## Adding a New Locale

1. Add locale to `src/i18n/config.ts`:

```typescript
export const locales = ['th', 'en', 'cn'] as const
```

2. Create message file `src/messages/cn/common.json`

3. Update middleware locale detection in `src/proxy.ts` (regex pattern)

## Adding New Translation Keys

1. Add key to **both** `src/messages/th/common.json` and `src/messages/en/common.json`
2. Use in component: `const t = useTranslations('namespace')`
3. Access: `t('keyName')`

For nested keys: `t('auth.loginTitle')` maps to `{ "auth": { "loginTitle": "..." } }`
